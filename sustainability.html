Sustainability documentation

Make your digital presence lighter, faster, and more resilient. Sustainability means practical choices that lower emissions and improve experience.

Performance budget

Set measurable limits before building:

  • Max page weight and script weight per template
  • Image format and size ceilings by device class
  • Lighthouse target thresholds for every release

Content operations

Keep pages clean over time:

  • Quarterly content pruning of outdated pages and PDFs
  • Reuse component patterns instead of one-off layouts
  • Compression defaults for every uploaded media asset

Infrastructure choices

Align hosting and deployment with sustainability goals:

  • Prefer green hosting options where available
  • Use caching and CDN strategy to reduce server load
  • Track energy impact alongside uptime and cost metrics
